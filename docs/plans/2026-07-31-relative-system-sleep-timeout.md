# ディスプレイ消灯後の相対スリープ時間

## 目的

AC時とバッテリー時について、ディスプレイ消灯時間と、その後にPCがスリープするまでの追加時間を一組として表示および変更できるようにします。
DisplayLightから適用した設定では、システムスリープがディスプレイ消灯より先にならない関係を保ちます。

## 完了条件

- Coreがディスプレイ消灯時間と追加時間からWindowsの絶対スリープ時間を計算する。
- Windowsアダプターが`VIDEOIDLE`と`STANDBYIDLE`を対象電源側ごとに一組として読み書きする。
- プリセット外と「Windowsで個別に設定」を自動修正せず表示する。
- AC時とバッテリー時の各カードで二つの選択と合計時間を表示し、一回の「適用」で変更する。
- 設定スキーマを移行し、既存のディスプレイ選択とAC限定設定を維持する。
- `pwsh -NoProfile -File ./scripts/verify.ps1`が成功する。
- 実機の電源状態を変える確認は今回実施せず、`docs/TESTING.md`へ残す。

## 対象外

- 手動のスリープ開始。
- Codex連携と作業完了後の自動スリープ。
- 任意の数値を入力するカスタム欄。
- 休止状態とModern Standby固有設定の変更。

## 作業開始時の設計

`DisplayLight.Core`はディスプレイ消灯プリセットだけを秒数へ変換しています。
`WindowsDisplayTimeoutService`は`VIDEOIDLE`のAC値とDC値を読み書きし、`MainWindowViewModel`とフライアウトは電源側ごとに一つのスライダーを公開しています。
設定スキーマは版1であり、AC時とバッテリー時のディスプレイ消灯プリセットを保存しています。

相対指定の決定は`docs/OPEN_QUESTIONS.md`のQ20、変換と復旧方針は`docs/adr/0008-relative-system-sleep-timeout.md`を正とします。
自動テストから実際の電源設定を変更しない安全規約を維持します。

## 実装手順

1. Coreへ追加時間プリセット、変換、現在値分類を追加し、境界値を単体テストします。
2. 電源設定ポートを二値の読み書きへ拡張し、Windowsアダプターで`STANDBYIDLE`と復旧処理を実装します。
3. 設定スキーマを版2へ移行し、追加時間の保存と旧版移行をテストします。
4. ViewModelへ二つの選択、合計表示、個別設定表示、一回の適用を追加し、既存の未適用状態を維持します。
5. WPFフライアウトへ追加時間スライダーと説明文を追加し、Automation名とアクセシビリティテストを更新します。
6. README、検証項目、実装と設計の整合性を見直し、標準検証を実行します。

## 発見と判断

- Windowsは相対値を保存しないため、UIの追加時間をCoreで絶対秒数へ変換します。
- 二つの電源設定は単一トランザクションで更新できないため、変更前の組を保持して失敗時に復旧を試みます。
- 手動の「ディスプレイをオフ」は`VIDEOIDLE`を一時的に短縮しますが、`STANDBYIDLE`は変更せず、追加時間の起点にはしません。
- ディスプレイ消灯を無期限にした場合も、利用者が最後に選んだ有限の追加時間は設定へ保持し、有限へ戻したときに復元します。
