# 0008 システムスリープをディスプレイ消灯からの追加時間で指定する

- 状態：Accepted
- 日付：2026-07-30

## 文脈

DisplayLightはディスプレイ消灯時間を変更し、一時的なシステムスリープ防止要求を保持できます。
しかし、システムスリープ時間を表示しないUIでは、スリープ防止を解除した後にPC本体がいつスリープするかを利用者が把握できません。

ディスプレイ消灯時間とシステムスリープ時間を独立した絶対時間として選ぶと、システムスリープのほうが先になる組み合わせを作れます。
この組み合わせでは、ディスプレイ消灯時間が実際の動作に現れません。

## 判断

AC時とバッテリー時の各カードで、ディスプレイ消灯時間とシステムスリープまでの追加時間を一組として扱います。
システムスリープは「画面オフの何分後」として選択し、最後の操作からの合計時間も表示します。

ディスプレイ消灯時間は`1分`、`5分`、`10分`、`30分`、`60分`、`無期限`とします。
システムスリープまでの追加時間は`同時`、`5分後`、`15分後`、`30分後`、`60分後`、`スリープしない`とします。
ディスプレイ消灯を`無期限`にした場合は、システムスリープも`スリープしない`に固定します。
固定中も最後に選択した追加時間を利用者設定へ保持し、ディスプレイ消灯を有限の時間へ戻した場合に復元します。

この相対指定はDisplayLightのUIとCoreで使うモデルです。
Windowsには、ディスプレイ設定サブグループの`VIDEOIDLE`とスリープ設定サブグループの[`STANDBYIDLE`](https://learn.microsoft.com/en-us/windows-hardware/customize/power-settings/sleep-settings-sleep-idle-timeout)へ、最後の操作からの絶対秒数をそれぞれ保存します。
例えば、ディスプレイ消灯が10分で追加時間が15分の場合、`VIDEOIDLE`へ600秒、`STANDBYIDLE`へ1500秒を保存します。
変更の反映には`PowerSetActiveScheme`を使用します。

「ディスプレイをオフ」ボタンは、`VIDEOIDLE`を一時的に短縮して発生させる一回限りの自動画面オフです。
この操作はWindowsのシステムスリープ時間を再設定せず、追加時間の計測開始条件にもなりません。

Windows側の現在値がDisplayLightのプリセットに一致しない場合は、実値を「プリセット外」として表示して自動修正しません。
システムスリープがディスプレイ消灯より先になる場合、またはディスプレイ消灯だけが無期限の場合は、「Windowsで個別に設定」と表示します。
利用者がDisplayLightのプリセットを選択して適用した場合だけ、相対指定から求めた値へ変更します。

## 結果

DisplayLightから適用した設定では、システムスリープがディスプレイ消灯より先になりません。
利用者は「画面が消えるまでの時間」と「通常のアイドル状態で、その何分後にPCがスリープするか」を同じカードで確認できます。

二つのWindows設定は単一のトランザクションでは変更できません。
そのため、適用前に両方の値を保持し、書き込み、反映、または読戻しに失敗した場合は変更前の組への復旧を試みます。
復旧後も両方の値を読み直し、実値を利用者へ表示します。

## 比較した案

システムスリープ時間を表示しない案では、スリープ防止を解除した後の動作をDisplayLight内で説明できないため採用しませんでした。

ディスプレイ消灯時間とシステムスリープ時間を独立した絶対時間として選ぶ案では、順序が逆転する組み合わせをUI側で個別に制限する必要があります。
選択を相対時間にすると順序関係を構造で保てるため、採用しませんでした。

システムスリープを自動的にディスプレイ消灯と同じ時間へ設定する案では、画面を消したままバックグラウンド処理を続ける猶予を選べないため採用しませんでした。
