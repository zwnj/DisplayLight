# 0010 プリセットを二行のセグメント選択で表示する

- 状態：Accepted
- 日付：2026-08-01
- 置換対象：ADR 0004の離散スライダーに関する表示判断

## 文脈

画面オフ時間とPCスリープまでの追加時間を離散スライダーとして縦に並べると、展開時のフライアウトが長くなります。
二つを左右へ並べる案は各選択肢の幅が不足し、ドロップダウンへ置き換える案は値を変更するまでのクリック数が増えました。

## 判断

各電源側の展開領域では、画面オフ時間とPCスリープまでの追加時間を、六つの等幅セグメントから直接選ぶ二行として表示します。
候補は常に表示し、一回のクリックまたはキーボード操作で選べる状態を維持します。
選択中の値は実線枠と太字、未適用変更がある場合の現在値は下線、キーボードフォーカスはフォーカス枠で区別します。

## 結果

二つの値を同時に比較でき、選択操作を増やさずに展開領域の高さを抑えられます。
時間へ比例する連続入力には見えなくなるため、六つの候補が固定プリセットであることも明確になります。
Automationでは従来どおり各項目を名前付きの選択肢として公開します。

## 比較した案

左右に二つのスライダーを並べる案は、固定幅のフライアウトでラベルと操作領域が狭くなるため採用しません。
画面オフとPCスリープを切り替えて片方だけ表示する案は、相対関係を同時に確認できないため採用しません。
ドロップダウンは高さを抑えられますが、候補を開く操作が増え、全候補も常時見えないため採用しません。
詳細設定を別ウィンドウへ移す案は、将来設定項目が増えた場合の選択肢として残します。
