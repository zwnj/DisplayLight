画面オフとPCスリープの時間設計

DisplayLightでは、PCのスリープを独立した時刻ではなく「画面が消えてからの追加時間」として選ぶ。これにより、PCが画面より先にスリープする設定を作らない。

結論

各電源側のカードで、最初に「画面をオフ」を選び、次に「PCをスリープ」を画面オフからの追加時間として選ぶ。DisplayLightは二つの選択をWindowsの絶対タイムアウトへ換算し、一回の「適用」で書き込む。[1][2]

表示例：画面を10分でオフ、PCをその15分後にスリープ。「PCスリープ：合計25分後」と表示する。

目的と範囲

現在のDisplayLightは、ディスプレイ消灯時間と一時的なスリープ防止を扱う。システムスリープ時間も同じ画面で扱い、スリープ防止を解除した後の動作を利用者が把握できるようにする。[1]

この仕様が対象とするのは、無操作時のディスプレイ消灯時間とシステムスリープ時間である。「今すぐ画面をオフ」は一回限りの補助操作であり、PCスリープまでの追加時間を開始するイベントにはしない。エージェント作業完了後の自動スリープも別機能として扱う。[2]

利用者に見せる時間関係

一つの流れとして選択する

  1. 最後の操作から、選択した時間が経過する。
  2. 画面をオフにする。
  3. 選択した追加時間だけ待つ。
  4. PCをスリープにする。

この順序をUIの構造で保つため、システムスリープの絶対時間を直接選ばせない。

Windowsの実際の計測：Windowsは「画面が消えた瞬間」を起点に別のタイマーを開始するのではない。ディスプレイとスリープの両方を、無操作時間に対する絶対秒数として保持する。相対表現はDisplayLightのUIモデルである。[4]

プリセット

二つのプリセット選択行は各6択とし、時間へ比例しない離散選択肢として等幅に配置する。各候補は一回のクリックで直接選べる。[6]

画面オフ時間とPCスリープ追加時間の選択肢
設定 選択肢 意味 Windowsへの値
画面をオフ 1分・5分・10分・30分・60分・無期限 最後の操作から画面を消すまで VIDEOIDLE = D
PCをスリープ 同時・5分後・15分後・30分後・60分後・スリープしない 画面オフ時間に追加する猶予 STANDBYIDLE = D + A

「同時」は追加時間0分を表す。「スリープしない」と「無期限」はWindowsへ0秒として保存する。[2][4]

Windows値への変換

ディスプレイ消灯時間をD、追加時間をA、Windowsへ保存するシステムスリープ時間をSとする。

D が無期限           → S = 0（スリープしない）
A がスリープしない   → S = 0（スリープしない）
それ以外             → S = D + A
代表的な変換例
画面をオフ PCをスリープ 画面のWindows値 スリープのWindows値 利用者への合計表示
10分 15分後 600秒 1500秒 合計25分後
30分 同時 1800秒 1800秒 合計30分後
5分 スリープしない 300秒 0秒 画面だけ5分後にオフ
無期限 スリープしない（固定） 0秒 0秒 どちらも無期限

UIの振る舞い

AC時とバッテリー時を別々に編集する

各カードに「画面オフ」と「PCスリープ」のプリセット行をこの順で置く。起動時は両方のカードを閉じ、カードごとに一つの「変更を適用」を置く。

合計時間を常に併記する

「15分後」だけではWindowsへ保存される値が分からないため、「PCスリープ：合計25分後」のように表示する。

画面が無期限なら追加時間を固定する

「画面オフ」が無期限の場合、「PCスリープ」は「スリープしない」に固定して選択行を無効にする。最後に選んだ追加時間は保持し、画面オフを有限へ戻したときに復元する。

スリープ防止との違いを明示する

スリープ防止中も電源設定は変更できる。補足文は「自動スリープだけを防止。画面は設定どおり消えます」とし、PCスリープだけを一時的に抑止していることを示す。[1]

既存のWindows設定

DisplayLight以外から設定された値を、起動や再読込みだけで変更しない。現在値を次の規則で分類する。

現在値の分類と表示
Windowsの状態 表示 自動修正
両方がプリセットへ一致し、順序も正しい 対応する二つの選択肢 しない
順序は正しいが、値または差分が選択肢にない 実値と「プリセット外」 しない
PCスリープが画面オフより早い 実値と「Windowsで個別に設定」 しない
画面オフが無期限で、PCスリープだけ有限 実値と「Windowsで個別に設定」 しない

利用者がプリセットを選び「適用」を押した場合だけ、DisplayLightの相対モデルから求めた組へ変更する。[3]

適用と失敗時の安全性

  1. 対象電源側のVIDEOIDLEとSTANDBYIDLEを読み、変更前の組として保持する。
  2. 選択した相対値から二つの絶対秒数を計算する。
  3. 二つの値を書き込み、電源プランを反映する。
  4. 両方を読み戻し、要求した値との一致を確認する。
  5. 書き込み、反映、読戻しのいずれかに失敗した場合は、変更前の組への復旧を試みる。
  6. 復旧の成否にかかわらず実値を再取得し、現在の状態とエラーを表示する。
制約：Windowsの二つの設定は単一トランザクションでは変更できない。復旧は試みられるが、完全な原子性は保証しない。[2]

設定保存と移行

AC時とバッテリー時について、画面オフの選択と追加時間の選択を保存する。既存設定からの移行では、画面オフの選択と「AC電源接続時のみ」を維持し、追加時間を両方とも「15分後」で初期化する。

移行と起動だけではWindows電源プランを変更しない。利用者が「適用」を押したときだけ二つのタイムアウトを書き込む。画面オフが無期限で追加時間を一時的に固定している場合も、最後に選んだ追加時間は設定へ残す。[1]

実装の受入条件

  1. Coreが全プリセットについてS = D + Aと無期限規則を単体テストで検証する。
  2. Coreがプリセット外、順序逆転、画面だけ無期限の各状態を区別する。
  3. WindowsアダプターがAC値とDC値を混同せず、二つの設定を書き込み、読戻しする。
  4. 部分失敗時に復旧を試み、復旧失敗後も実値を表示する。
  5. ViewModelが一つの「適用」で二つの選択を扱い、未適用状態と合計時間を公開する。
  6. 「画面をオフ」ボタンがスリープ時間を変更しない。
  7. 自動テストは実際の消灯やスリープを実行しない。
  8. 実機ではAC時とバッテリー時、スリープ防止中の画面消灯、解除後のスリープを復旧手順付きで確認する。

自動検証済み 2026年7月31日時点のコードは、ディスプレイ消灯時間とシステムスリープ時間の一組を読み書きする。実際の電源状態を変える実機確認は未実施である。[5]
